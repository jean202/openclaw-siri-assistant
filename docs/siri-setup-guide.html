OpenClaw Siri Assistant

iPhone Siri Shortcut Setup Guide

How It Works

Siri → Shortcut → Tunnel → OpenClaw → Voice Reply

Siri voice input is sent to your local OpenClaw AI agent via a Cloudflare tunnel, and the response is spoken back.

Setup Method

Auto Generate
(recommended)
Manual Setup
(fallback)

A. Auto Generate (Recommended)

Run this on your Mac where the bridge is running:

Terminal Command
node generate-shortcut.js

This creates AskOpenClaw.shortcut with your current URL and secret baked in.

Transfer to iPhone

1
AirDrop (fastest)

Right-click AskOpenClaw.shortcut → Share → AirDrop → your iPhone

2
Tap to import

iPhone will open the Shortcuts app. Tap Add Shortcut.

3
Say "Hey Siri, Ask OpenClaw"

Siri will ask what you want to know, then speak the AI response.

Tunnel URL changes on every restart. Re-run node generate-shortcut.js and re-import after restarting the bridge.

B. Manual Setup

Create the shortcut directly on your iPhone.

Your Configuration

Bridge URL
Run cat .tunnel-url on Mac to get this
API Secret
Run cat .secret on Mac to get this

Step-by-Step

1
Open Shortcuts App

Tap + to create a new shortcut. Name it "Ask OpenClaw".

2
Add Action: Ask for Input

Search "Ask for Input". Set prompt to:
What would you like to ask?
Input Type: Text

3
Add Action: Get Contents of URL
URL{your tunnel URL}/ask
MethodPOST
Body TypeJSON

Add these JSON fields:

secret{your API secret}
messageProvided Input (tap to select the variable from step 2)
session_idsiri-iphone
4
Add Action: Get Dictionary Value

Key: reply
From: Contents of URL (auto-selected)

5
Add Action: Speak Text

Input: Dictionary Value (auto-selected)
Wait Until Finished: ON

6
Done!

Tap the play button to test, then try "Hey Siri, Ask OpenClaw".

Troubleshooting

?
"The request timed out"

Bridge or tunnel may be down. Check Mac: ./check-url.sh

?
"Invalid secret"

Secret mismatch. Re-generate shortcut or update the secret value manually.

?
Siri says nothing / empty response

OpenClaw may not be installed or in PATH. Check logs: cat logs/requests.log

?
Tunnel URL changed

Quick tunnels get a new URL on each restart. Re-run node generate-shortcut.js and re-import.

Tip: For a permanent URL, set up a Named Tunnel with a custom domain. Then you only need to set up the shortcut once.

API Quick Reference

Endpoint
POST {tunnel_url}/ask
Request Body (JSON)
{ "secret": "your-api-secret", "message": "your question here", "session_id": "siri-iphone" }
Response (JSON)
{ "reply": "AI response text" }
